## Demo 1: From Raw Data to Executive Story

### Explore data sources in Copilot Chat
- `what's the official data source for malaysia's population`
- `what's the official data source for malaysia's population projection`

### Download demo file (based on the official data sources)
[population_malaysia.xlsx](https://github.com/ningweinw/demo/raw/refs/heads/master/BNM/data/population_malaysia.xlsx)

### Clean and transform data
Open __population_malaysia.xlsx__, select __population_malaysia__ sheet.<br>
Open __Copilot__ and select __Allow editing__ mode:
- `Format the data in this worksheet as a table`
- `Identify data quality issues such as inconsistency, wrong format, missing value, duplicates`
- `In the age column, cells with labels '9-May' and '14-Oct' are Excel-converted age bands, replace them with text value: '5-9' and '10-14`

Select __projection__ sheet:
- `Does the data in this sheet need to be restructured to facilitate better data analysis?`
- `Make this change, create the table in a new sheet`

### Analyze data
Select __population_malaysia__ sheet. Open __Copilot__ and select __Chat only__ mode:
- `What questions can I investigate using this data if I wanted to understand Malaysia's ageing population`

Open a new Word doc, copy both the prompt and Copilot response to the doc:
- `Analyse how Malaysia's population aged 65 and above has changed over time. Compare it with the total population and younger age groups`
- `Identify periods where the 65+ population increased noticeably`
- `What are the key insights to Malaysia's aging population?`
- `Which insight would be most important for the government, and why?`
- `Review this data vs the "Projection Data" sheet, show me the actual vs estimated population patterns`
- `Using data in "Projection Data" sheet, summarize the projected population to 2060, supported by key data points in a table`

### Calculate and highlight data
Select __Allow editing__ mode:
- `Add a column to calculate the percentage of the total population in the same year, apply different background colors using 5 value-based bands: <1%, 1-5%, 5-10%, 10-25%, >25%`

### Visualize data
- `Create a chart in a new sheet, showing how Malaysia's population structure has changed over time`

### Create executive presentation using the analysis
Open an existing PowerPoint with the right template. Open __Copilot__:
>Using \[_Attach the Word doc containing the analysis result_\] and the styles in this powerpoint, create a new powerpoint deck with following slides:
>
>Slide 1: Malaysia is getting older<br>
>A simple opening statement and one strong visual.<br>
>
>Slide 2: Malaysia's age structure is changing<br>
>Show population change over time for different age groups<br>
>
>Slide 3: The change becomes clearer when we look ahead<br>
>Show population projection to 2060<br>
>
>Slide 4: Why could this matter?<br>
>Show key insights to the population changes, and what is most important to the government<br>

## Demo 2: From Meeting to Management Update

### Prepare for an upcoming meeting
Click an upcoming meeting in Outlook or Teams:
- `Help me prepare for this meeting`
- `Suggest 5 icebreaking questions`

### Engage in a live meeting
Open __Copilot__ in the live meeting:
- `Catch me up on the meeting so far`
- `Who have participated in the discussion? Summarize what each person has discussed`

### Capture key points in an ended meeting
Selected an ended meeting, open __Copilot__:
- `What different views have participants expressed?`
- `What questions or issues have not yet been resolved?`
- `What assumptions are we making in this discussion?`
- `Tabulate all the action items, owners and deadline`

### Generate management update
Capture meeting information in a specific structure:
>Using the meeting information, draft a management update. Structure it as:
>1. Purpose
>2. Key observations
>3. Decisions
>4. Agreed actions
>5. Next steps

Export the response to a Word doc. Open the doc, open __Copilot__:
- `Transform these meeting minutes into an executive-ready summary for senior management. Focus on outcomes, decisions, business impact, risks, management attention required, and key actions. Remove operational detail and repetition. Keep the Executive Summary to no more than five bullets, and do not add information that is not supported by the original minutes.`
- `Review the doc, suggest areas of improvement to make it more executive ready`
